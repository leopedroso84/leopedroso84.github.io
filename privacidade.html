Política de Privacidade

Última atualização: 5 de agosto de 2026.

Este site é uma página profissional pessoal e informativa de Leandro Augusto Pedroso de Souza. Seu objetivo é apresentar experiência, competências, projetos e formas de contato.

1. Dados coletados diretamente

Este site não possui cadastro de usuários, área de login, comentários, formulário próprio ou banco de dados. Portanto, não realiza coleta direta de informações pessoais por meio dessas funcionalidades.

2. Links e serviços de terceiros

O site contém links para serviços externos, como GitHub, WhatsApp e e-mail. Ao utilizar esses serviços, aplicam-se os termos e políticas de privacidade das respectivas plataformas.

3. Conteúdo carregado do GitHub

A página de projetos pode consultar a API pública do GitHub para exibir repositórios públicos do perfil leopedroso84. Essa consulta é feita diretamente entre o navegador do visitante e o GitHub.

4. Hospedagem

Este site é hospedado pelo GitHub Pages. O GitHub pode processar dados técnicos de acesso, como endereço IP, tipo de navegador, registros de segurança e informações necessárias ao funcionamento da hospedagem, conforme suas próprias políticas.

5. Cookies

Este site não instala cookies próprios para publicidade, rastreamento ou criação de perfis. Serviços externos acessados por links podem utilizar tecnologias próprias.

6. Segurança

O site utiliza conexão HTTPS fornecida pelo GitHub Pages, ajudando a proteger o tráfego entre o navegador e o servidor de hospedagem.

7. Contato

Para dúvidas sobre esta política ou sobre o conteúdo do site, envie um e-mail para leopedroso84@icloud.com.
