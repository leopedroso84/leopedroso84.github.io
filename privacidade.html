Política de Privacidade

Última atualização: agosto de 2026.

Este é um site profissional pessoal e informativo. Ele não possui cadastro de usuários, área de login, sistema próprio de comentários nem coleta direta de dados pessoais.

Links externos

O site contém links para serviços de terceiros, como GitHub, e-mail e WhatsApp. Ao acessar esses serviços, aplicam-se as políticas de privacidade de cada plataforma.

Hospedagem

O site é hospedado pelo GitHub Pages. Informações técnicas de acesso podem ser processadas pelo GitHub conforme suas próprias políticas e medidas de segurança.
