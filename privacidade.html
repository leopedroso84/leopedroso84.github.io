Política de Privacidade

Última atualização: 17 de agosto de 2026.

Esta é a página institucional da Pedroso Tech. Ela apresenta a marca, seus territórios de atuação e canais externos de contato.

1. Dados coletados diretamente

O site não possui cadastro de usuários, login, comentários, formulário próprio, analytics ou banco de dados. Não realiza coleta direta de dados pessoais por essas funcionalidades.

2. Contato por canais externos

Os links de e-mail, WhatsApp, GitHub, Instagram e Facebook levam a serviços de terceiros. Ao utilizá-los, aplicam-se os termos e as políticas de privacidade de cada plataforma. A Pedroso Tech não controla o tratamento de dados realizado por esses serviços.

3. Hospedagem

O site é hospedado pelo GitHub Pages. O GitHub pode processar dados técnicos necessários para a entrega e segurança da hospedagem, como endereço IP e informações do navegador, conforme suas próprias políticas.

4. Cookies

Este site não instala cookies próprios para publicidade, rastreamento ou criação de perfis. Serviços externos acessados por links podem utilizar tecnologias próprias.

5. Segurança

A versão publicada pelo GitHub Pages utiliza HTTPS, protegendo o tráfego entre navegador e hospedagem.

6. Contato

Para dúvidas sobre esta política ou sobre o site, escreva para contato@pedrosotech.com.br.

7. Revisões

Esta política poderá ser atualizada quando houver alteração relevante nas funcionalidades ou no tratamento de dados do site.
